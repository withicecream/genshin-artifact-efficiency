Genshin Artifact Efficiency — Safe Cleaner

Load a GOOD export, see Keep / Maybe / Discard. Maximum-safety mode: an artifact is only ever marked DISCARD when even perfect future rolls cannot make it useful for any stat archetype. Everything runs in your browser — your data never leaves this page.
Get a GOOD file from Genshin Optimizer (Database → Export) or a scanner (Adepti / Amenoma / Artiscan). Nothing is uploaded — parsing happens locally.
Score = best of all archetypes (crit / atk / hp / def / em-reaction / er-support / heal) of Σ substatRollValue × archetypeWeight × mainStatFit. Discard requires the optimistic score (assuming every remaining roll lands perfectly) to stay below the Maybe threshold — so true keepers are never cut.
